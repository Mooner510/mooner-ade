# 미확인 항목

- **브라우저·Electron 화면 E2E**: 현재 세션에 제어 가능한 브라우저 연결이 없습니다. `docs/TESTING_GUIDE.md`의 격리 환경에서 Codex·Cursor `/stats` 열기, Cursor 대기열의 중단 후 전송, 터미널의 대화 선택·중단 확인·취소, 왕복 전환 후 이전 문맥으로 응답하기를 확인합니다. 기존 작업용 터미널은 사용하지 않습니다.
- **Windows 실제 실행**: Windows의 Cursor 프로세스 식별·`CURSOR_CONFIG_DIR` 유지·SQLite 복원·터미널 전환을 실제 설치된 CLI로 확인해야 합니다. 프로세스 문자열 검사와 저장소 검사는 실제 Windows 실행을 대신하지 않습니다.
- **Cursor 실제 청구 조회**: 해당 API 키의 계정과 로컬 세션에 사용량 조회가 활성화된 환경에서 실제 토큰·USD 비용을 확인해야 합니다. 보고가 늦거나 조회가 거절되면 값이 미제공으로 남는지도 확인합니다. 새 키·로그인은 사용자가 직접 준비합니다.

모든 항목을 확인하면 이 폴더를 삭제합니다.
