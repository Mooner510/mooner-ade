# 실제 Claude Code(API 키)로 본 채팅 UI 재점검 (2026-11-13)

격리 세션에서 실제 `claude` CLI를 **API 키로만** 실행해 확인했습니다(모델 Haiku 5.5 · Effort 낮음). 세션은 `REAL_AGENTS=1 VERIFY_OUT=<경로> CHROME=<경로> node scripts/verify/start-ui.mjs`로 띄우고, 설정 › AI 툴 › Claude Code › 채팅 인증에 키를 직접 넣습니다(임시 HOME이라 CLI 로그인이 없어 키로만 실행됨). 서버 코드를 고친 뒤에는 `REAL_AGENTS=1 VERIFY_OUT=<경로> node scripts/verify/restart-ui.mjs`로 서버만 다시 띄웁니다(Chrome 유지).

| API 키 교체 | 실행 중인 Claude 채팅이 있는 상태에서 설정의 API 키를 바꾼 뒤 메시지 보내기 | 다음 메시지가 새 키로 성공한다(서버 재시작 없이). 응답 중이었다면 그 턴이 끝난 뒤 바뀐다. 인증 실패는 빨간 오류 상자 하나로만 보인다(같은 문장이 답변으로 한 번 더 나오지 않음) |
