# 도구 묶음 스크롤 힌트 / 전체 보기 테스트

검증 상태: `pnpm typecheck` 통과. 화면 동작은 아직 직접 확인하지 않았습니다.

1. 도구를 3개 이하로 호출하는 턴을 실행한다 (예: 파일 3개 읽기).
   - 실행 중 헤더에 "전체 보기"와 화살표가 **없고**, 헤더를 눌러도 반응이 없다.
   - 끝나면 "도구 n개 호출 완료 · 펼치기" 한 줄로 접히고, 펼치면 n개가 모두 보인다.
2. 도구를 5개 이상 호출하는 턴을 실행한다.
   - 실행 중 목록이 위쪽 가장자리에서 흐려지고 "↑ 위 n개 더" 칩이 뜬다. 끝을 따라가는 중에는 아래 칩이 없다.
   - 위로 스크롤하면 위·아래 양쪽이 흐려지고 "↓ 아래 n개 더" 칩이 뜬다. 칩을 누르면 해당 방향으로 한 화면 가까이 스크롤된다.
   - 맨 끝/맨 처음에 닿으면 해당 칩이 사라진다.
   - "전체 보기"를 누르면 전부 펼쳐지고 칩이 사라진다. "접기"로 돌아온다.
3. 목록 안의 도구 카드를 열어 높이가 커지면 칩 개수가 따라 바뀌는지 본다.
