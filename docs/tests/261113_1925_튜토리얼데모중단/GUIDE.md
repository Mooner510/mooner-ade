# 튜토리얼 Chat 데모를 승인 카드가 떠 있을 때 넘기기

- 일시: 2026-11-13 19:25 (KST) · 브랜치: `feat/tutorial-hints`
- 상태: 미확인 (아래 한 항목만)

## 목적과 의도한 결과
튜토리얼 Chat 단계의 시연 대화가 승인·질문 카드를 띄운 채 기다릴 때 '다음'(또는 '이전')으로 넘기면, 데모가 멈추면서 그 카드도 사라져야 한다(`chat-demo.ts`의 `stop()`이 열린 요청을 `approval/cancelled`로 거둠). 카드와 ⚠ 표시가 남거나 입력창이 가려진 채로 남으면 실패.

## 환경
- 모드: A 더미 (`node scripts/verify/start-ui.mjs`), 새 데이터(첫 실행)

## 절차
1. 첫 실행 튜토리얼을 Chat 단계까지 진행한다.
2. 시연 대화에서 Bash 승인 카드나 질문 카드가 뜨는 순간 '다음'을 누른다.
3. '이전'으로 Chat 단계에 돌아와 카드가 남아 있지 않은지, 입력창이 보이는지 확인한다.

## 이번 세션에서 확인한 것
- 첫 실행: 테마·강조 색 화면 → 튜토리얼, 건너뛰기 없음
- 이전 튜토리얼을 끝낸 사용자(저장된 설정 `onboarded: true`, `tourVersion` 없음): 설정 화면 없이 튜토리얼만, 건너뛰기 없음
- 앱의 기존 `.hint` 문구(프로젝트 선택 화면 등)가 고정 위치 카드로 바뀌지 않음(`position: static`)
