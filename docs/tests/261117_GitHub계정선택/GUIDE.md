# 실제 GitHub 인증 확인 (미확인)

실제 계정의 자격 증명과 설치 앱은 사용하지 않았습니다. 아래 항목은 실제 계정에 접근할 수 있는 사람이 임시 `ADE_DATA_DIR`의 개발 앱에서 확인합니다. 토큰은 기록하지 않습니다.

1. github.com 계정 두 개가 등록된 `gh` 환경에서 설정 → 플러그인 → GitHub 연결을 열고 두 계정이 표시되는지 확인합니다.
2. 비활성 계정을 선택하고 그 계정만 접근할 수 있는 비공개 플러그인의 업데이트를 조회합니다. 앱 재시작 후 선택이 유지되고 `gh`의 활성 계정은 그대로인지 확인합니다.
3. 선택 계정이 인증 불가인 환경에서 다른 계정이나 시스템 Git 인증으로 전환되지 않고 오류가 나오는지 확인합니다.
4. `gh`가 없고 Git credential helper가 등록된 별도 환경에서 같은 조회가 시스템 인증으로 동작하는지 확인합니다. Windows의 실제 credential helper도 미확인입니다.

모두 확인한 뒤 이 폴더를 삭제합니다.
