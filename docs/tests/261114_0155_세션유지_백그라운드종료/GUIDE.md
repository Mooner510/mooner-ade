# 앱 종료 다이얼로그 · 백그라운드로 남기기 · 업데이트 중 Chat 유지

- 일시: 2026-11-14 01:55 (KST) · 브랜치: `feat/session-keep`
- 이 GUIDE는 이번 세션에서 확인하지 못한 항목만 담습니다. 모두 확인되면 이 폴더를 삭제합니다.

## 목적
앱 X(또는 ⌘Q)를 누르면 터미널이나 채팅이 살아 있을 때 `백그라운드로 남기기 / 종료 / 취소`를 묻는다. 백그라운드를 고르면 앱과 서버만 꺼지고, 터미널과 채팅 CLI는 pty-host에 남아 다음 실행 때 그대로 이어진다. 업데이트로 앱을 다시 시작할 때도 터미널과 채팅(진행 중인 응답 포함)이 끊기지 않는다.

## 미확인 항목
| 항목 | 못 한 이유·필요한 것 | 확인 절차 | 기대 |
|---|---|---|---|
| 종료 다이얼로그 | Electron 앱은 userData가 설치 앱과 같은 폴더로 고정이고 single-instance lock도 같아서 격리 실행이 안 된다. 사람이 `pnpm dev`나 패키지 빌드로 확인해야 한다 | 터미널 1개와 채팅 1개(메시지 한 번 보냄)를 연 상태에서 창 X를 누른다. 취소를 고른다 | 버튼 3개와 "터미널 1개와 채팅 1개가 열려 있습니다." 문구가 나온다. 취소하면 창이 그대로 남는다(창 없는 앱이 되지 않는다) |
| 백그라운드로 남기기 | 위와 같다 | 채팅에 오래 걸리는 작업을 시킨 뒤 X를 누르고 백그라운드로 남기기를 고른다. 1분 뒤 앱을 다시 실행한다 | 앱 창은 사라지지만 `pty-host.js`와 `claude` 프로세스는 남는다. 다시 실행하면 터미널 스크롤백이 이어지고, 채팅은 그사이에 끝난 응답까지 보인다 |
| 종료 | 위와 같다 | 같은 상태에서 종료를 고른다 | `pty-host.js`와 `claude` 프로세스가 모두 끝난다. 다시 열면 대화가 저장되어 있다 |
| 업데이트 재시작 | 실제 새 릴리스가 필요하다 | 이 변경이 들어간 버전을 설치한 뒤, 다음 버전으로 업데이트할 때 채팅이 응답 중인 상태에서 "지금 업데이트"를 누른다 | 업데이트 안내에 "터미널과 채팅, 그 안의 작업은…"이 나온다. 재시작 뒤 응답이 끊기지 않고 끝까지 나온다 |

## 참고
- 이번 세션에서 확인한 것:
  - 서버 레벨(격리 서버, 소스 pty-host, 가짜 claude): 정상 종료 뒤 새 서버가 응답 중인 턴을 이어받아 끝냈고, 승인 대기 카드도 유지됐다. 두 경우 모두 새 claude 프로세스는 뜨지 않았다.
  - Chrome: 탭 X 확인 다이얼로그.
- 이 변경 전 버전에서 넘어오는 첫 업데이트에서는 옛 pty-host가 `proc`을 지원하지 않는다. 그때만 채팅이 기존처럼 끊기고, 백그라운드는 30분까지만 유지된다.
